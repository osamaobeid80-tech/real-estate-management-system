# 🗄️ نظام إدارة العقارات — مكتب عقاري صغير

تطبيق ويب متجاوب (Responsive PWA) متكامل لإدارة عقود ووحدات مكتب عقاري صغير: تتبّع المستأجرين، قيمة الإيجارات، الدفعات الدورية، تواريخ الاستحقاق، الملاحظات التشغيلية، والتقارير.

## 🎯 هدف المشروع
تمكين مكتب عقاري صغير من إدارة وحداته وعقوده ومدفوعاته من واجهة واحدة سهلة، تعمل على كل الأجهزة والمنصات دون الحاجة لتطبيقات منفصلة لكل نظام تشغيل.

---

## 🏗️ هيكلية المجلدات في هذا المستودع
* **`/`** (الجذر): يحتوي على الواجهة الأمامية الثابتة (Static Web App).
* **`/backend`**: كود الخلفية الفعلي الكامل المبني باستخدام **Node.js + Express + PostgreSQL + JWT**.
* **`/frontend-react`**: الواجهة الأمامية المتطورة المبنية بـ **React + Vite** والمتصلة بالـ Backend.
* **`docker-compose.yml`**: لتشغيل كامل الحزمة (قاعدة البيانات + الخلفية + واجهة React) عبر حاويات Docker بأمر واحد.

---

## 🗺️ خريطة الصفحات (Sitemap)

| الصفحة | المسار | الوصف |
|---|---|---|
| لوحة التحكم | `index.html` | إحصائيات، تنبيهات استحقاق، ورسوم بيانية |
| العقارات | `properties.html` | قائمة المباني، بحث، وفلترة وإضافة/تعديل/حذف |
| الوحدات | `units.html` | قائمة الوحدات التابعة لكل عقار وحالتها |
| العقود | `contracts.html` | قائمة عقود الإيجار وإدارتها بالكامل |
| تفاصيل الوحدة | `unit-detail.html` | بيانات الوحدة، العقد المرتبط، وجدول الدفعات |
| إدارة المدفوعات | `payments.html` | كشف المدفوعات المركزي وتتبع المتأخرات |
| التقارير | `reports.html` | رسوم بيانية تفاعلية وتصدير بيانات CSV |

## 🚀 طريقة التشغيل السريع عبر Docker Compose
لتشغيل قاعدة البيانات والخلفية وواجهة React معاً محلياً، تأكد من تثبيت Docker ثم نفّذ الأوامر التالية:

```bash
# 1) نسخ ملف متغيرات البيئة وتعديل القيم
cp .env.docker.example .env.docker

# 2) بناء الحاويات وتشغيل الخدمات
docker compose --env-file .env.docker up -d --build

# 3) إنشاء حساب مسؤول النظام الأول
docker compose exec backend npm run create-admin -- "الاسم الكامل" "admin@example.com" "StrongPass123!" "مسؤول النظام"
```
* رابط واجهة React بعد التشغيل: `http://localhost:8080`
* رابط الـ API للتأكد من الحالة: `http://localhost:4000/health`
